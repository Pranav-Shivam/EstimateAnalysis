Example module (takeoff — full layer order):

api/v1/takeoff/
├── routes.py       # route handlers, def not async def, ApiResponse[T] envelope
├── request.py      # Pydantic request models, from_attributes=True
└── response.py     # Pydantic response models

app/takeoff/
├── services.py            # business logic, calls self._repo only
├── repository.py          # DB ops via PostgressClient, _dict_to_*() converters
├── schemas.py              # @dataclass, matches Postgress columns
├── constants.py            # DB coords, sort whitelist, search cols
├── enums.py                # SortOrder(str, Enum) + domain enums
├── mapping.py              # static dict literals
├── helper.py               # generate_id(), safe_sort_column()
├── project_estimate_engine.py   # extra: calc logic specific to takeoff
├── rule_engine_bridge.py         # extra: bridges to core/rule_engine
├── breakdown_persist.py           # extra: persistence helper
└── Postgress_udfs.py               # extra: UDF wrappers
